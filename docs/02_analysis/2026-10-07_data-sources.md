# 🔬 분석: 데이터 출처 (시세·뉴스 API)

## 결론 (먼저)
- **선택**
  - 시세(국내·미국 지수, 환율): **FinanceDataReader 를 1차 출처**로 쓰고, `QuoteProvider` 인터페이스 뒤에 둔다. 미국 쪽 예비 출처는 yfinance.
  - 브리핑에 싣는 시세는 **지수·환율·금리의 종가와 등락률 수준**으로 한정한다. 개별 종목 시세표는 싣지 않는다.
  - 금리: 출처를 **아직 확정하지 않는다.** ECOS(국내)와 미국 금리 출처를 플랜의 첫 PoC 로 확인한다.
  - 국내 뉴스: **언론사 RSS(한국경제·매일경제·연합뉴스 경제 섹션)** 의 제목·요약·링크를 LLM 에 넣어 요약하고, 원문 링크를 함께 싣는다. **DART 공시**를 보조 재료로 쓴다.
  - 미국 뉴스: **Marketaux 무료 플랜**. SEC EDGAR 는 필요해지면 붙인다.
- **이유 3줄**
  1. 운영 주체가 개인이고 무료·비상업·소수 수신이라, 월 $19~$449 의 상용 플랜과 별도 재배포 계약은 규모에 맞지 않는다.
  2. 발송 시각(국내 개장, 미국 개장)에 직전 장의 종가가 있어야 하는데, 공공데이터포털은 다음 영업일 13시 이후에야 갱신돼 두 시각 모두에 맞지 않는다.
  3. 네이버 검색 API 는 약관이 AI 입력을 명시적으로 금지해 "LLM 요약" 요구와 정면으로 부딪힌다. RSS 에는 그런 조항이 없다.

## 문제 분해
1. **시세 — 국내 지수**(KOSPI·KOSDAQ): 미국 개장 브리핑에 당일 종가가 필요하다.
2. **시세 — 미국 지수**: 국내 개장 브리핑에 전일 미국 종가가 필요하다.
3. **환율·금리**: 두 브리핑 모두에 들어간다.
4. **뉴스 — 국내**: LLM 요약이 가능한 출처여야 한다.
5. **뉴스 — 미국**: 무료 플랜이 프로덕션 사용과 실시간에 가까운 제공을 허용해야 한다.
6. **약관**: 본인 외 "소수의 지인"에게 보내는 것이 각 출처의 "제3자 제공" 조항에 걸리는지.

## 버린 옵션과 이유
- **공공데이터포털 주식시세정보**: 갱신이 "기준일자로부터 영업일 하루 뒤 오후 1시 이후"다. 국내 개장(09:00) 브리핑에도, 미국 개장 브리핑에도 직전 종가가 없다. 약관 이전에 시각이 맞지 않는다.
- **KRX Open API**: 비상업 조건은 충족하지만 제11조②("may not provide the data … to any third parties")가 지인 발송과 직접 충돌한다. 약관이 명시적으로 막는 출처를 굳이 승인 절차까지 밟아 쓸 이유가 없다.
- **KIS Developers**: 계좌가 필요하고, 제3자에게 서비스를 제공하는 제휴는 제도권 금융회사만 대상이다. 지수 종가만 필요한 용도에 비해 진입 조건이 무겁다.
- **pykrx**: 일부 API 에 KRX 로그인 환경변수가 필요하다. 국내 지수만 다루므로 미국·환율은 어차피 다른 출처가 필요하다.
- **Alpha Vantage·FMP·Twelve Data·Massive 무료 플랜**: 약관이 모두 개인·비상업·비표시 전제라 비공식 라이브러리보다 약관상 나은 점이 없는데, 키 관리와 일 25~800건 한도만 추가된다. Finnhub 는 한도·요금을 공식 페이지에서 확인하지 못했다.
- **상용 유료 플랜**: 상업화 목표가 없다. 수신자가 본인과 소수 지인인 단계에서 월 고정비와 재배포 계약은 과하다.
- **네이버 검색 API**: 약관이 "데이터를 AI 에 입력하거나 학습, 개선, 평가 및 노출 등에 활용하는 행위"를 금지한다. LLM 요약이 요구사항이므로 쓸 수 없다. 가공 없이 노출해야 한다는 조항도 요약과 맞지 않는다.
- **카카오/다음 검색 API**: 뉴스 검색이 문서에 없다.
- **빅카인즈**: 조건을 확인하지 못했고, 사이트가 전재·복제·배포를 금지한다. 미확인 상태로 선택할 근거가 없다.
- **NewsAPI.org·GNews 무료**: 프로덕션 사용 금지에 12~24시간 지연이다. 개장 시각 브리핑에 쓸 수 없다.
- **Google News RSS**: 피드 자체에 개인 피드 리더 외 사용 금지 문구가 박혀 있다. 언론사 RSS 중 한국경제·매일경제는 그런 문구가 없으므로 그쪽이 낫다.

## 전제 (깨지면 재검토)
- **수신자는 본인과 소수의 특정 지인이고, 무료이며, 광고·수익이 없다.** 수신자를 공개 모집하거나 유료화하면 이 분석의 시세·뉴스 선택은 전부 다시 봐야 한다. 그때는 재배포 권리가 있는 유료 데이터와 뉴스 이용허락 계약이 필요하다.
- **선택한 어떤 출처도 "지인에게 보내도 된다"고 명시하지 않는다.** 비상업·소규모·가공 지표라는 조건에서 남는 회색 지대를 감수하는 결정이다. 엄격하게 깨끗한 구성은 수신자가 본인뿐인 경우다. 이 판단은 법률 자문이 아니다.
- 브리핑은 원시 시세표가 아니라 지수·환율·금리의 종가와 등락률, 그리고 LLM 이 쓴 해석을 싣는다.
- 뉴스는 기사 본문을 옮기지 않는다. 제목·RSS 요약을 입력으로 LLM 이 자기 문장으로 흐름을 요약하고 원문 링크를 붙인다. 리서치에서 "제목·요약(LLM 포함)" 에 대한 언론진흥재단의 별도 문구는 찾지 못했다.
- FinanceDataReader 가 KOSPI·KOSDAQ·미국 3대 지수·원/달러 환율을 두 발송 시각에 직전 종가 기준으로 돌려준다. 리서치는 "지수·환율 포함"까지만 확인했고 심볼별 동작은 확인하지 않았다.
- 한국경제·매일경제 RSS 의 이용 조건은 RSS 페이지에 문구가 없다는 것까지만 확인했다. 각 사 저작권 규약은 보지 못했다.

| 버전 미고정 의존성(pyproject 에 제약 없음)으로 라이브러리 동작 변화 | 중 | 수집 실패 | 도입 시 버전을 고정한다 (FinanceDataReader 0.9.202, yfinance 1.7.0 기준) |
| RSS 요약(description)이 너무 짧아 LLM 요약이 제목 나열에 그침 | 중 | 브리핑 품질 저하 | PoC 에서 실제 피드로 요약 품질을 본다 |

출처는 전부 무료이고 계약이 없다. 인터페이스(`QuoteProvider`, `NewsProvider`) 뒤에 두면 교체 비용은 어댑터 하나다.
단, 금리 출처와 FinanceDataReader 의 심볼별 동작은 플랜 초반의 PoC 로 확인한다.

## 플랜 단계로 넘기는 것
- 금리 출처 PoC (ECOS, 미국 금리). 리서치에서 조건을 확인하지 못했다.
- FinanceDataReader 로 두 발송 시각에 필요한 값이 실제로 나오는지 확인.
- 휴장일 처리 (국내·미국 휴장일이 다르다).
- LLM 선택과 요약 프롬프트는 이 분석의 범위 밖이다.
