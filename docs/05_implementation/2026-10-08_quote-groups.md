첫 실제 메일을 받은 사용자가 "시세가 8개밖에 안 된다"고 했다(2026-10-08). 사용자가 고른 네 묶음을 모두 넣고, 묶음별 소제목으로 보여 주기로 했다. 플랜에 없던 Task 라 `task add` 로 추가했다.

## 한 일

- `Market` 에 `ASIA`, `COMMODITY` 추가.
- 수집이 슬롯과 무관하게 **모든 심볼**을 가져온다 (`SLOT_MARKETS` 삭제).

- yfinance 예비 티커 표에 새 심볼 추가.
- 작성기가 시세를 묶음별 섹션으로 나눈다: 미국 증시 / 국내 증시 / 아시아 증시 / 금리 / 환율 / 원자재·코인.
- 심볼 확인 결과는 [quote-symbols-poc](../01_research/2026-10-08_quote-symbols-poc.md).

## 왜 이렇게 했나
| 결정 | 대안 | 고른 이유 |
|---|---|---|
| 슬롯별 시장 필터를 없앴다 | 슬롯마다 시장 목록을 늘린다 | 두 슬롯 모두 전부 싣게 되어 목록이 같아졌다. 슬롯의 차이는 "무엇을 먼저 보여 주나"뿐이고 그건 작성기의 일이다 |
| 국내 개장은 미국 증시가 맨 위, 미국 개장은 국내 증시가 맨 위 | 고정 순서 | 각 브리핑이 전하려는 것은 직전에 마감한 시장이다 |
| **첫 번째로 값이 있는 묶음만** 필수 섹션 | 모든 묶음이 필수 / 맨 앞 묶음이 필수 | "시세가 하나라도 있으면 보낸다"는 기존 판정을 그대로 유지한다. 모든 묶음을 필수로 두면 아시아 하나가 실패해도 메일이 안 나간다 |
| 시세가 하나도 없으면 빈 필수 섹션 "시세" 하나 | 섹션 없음 | 발송 불가 판정이 기존과 같은 경로를 탄다 |
| 환율에서 "원" 단위를 뺐다 | 심볼마다 단위를 둔다 | 엔/달러·유로/달러·달러 인덱스가 들어오며 "원"이 틀린 말이 됐다. 이름이 이미 무엇의 값인지 말한다. 등락폭과 등락률은 그대로 둘 다 싣는다 |
| 10 미만인 값은 소수 넷째 자리 | 전부 둘째 자리 | 유로/달러 1.1204 → 1.1203 은 둘째 자리에서 보이지 않는다 |
| 원/엔은 `scale=100` 으로 수집 조립에서 곱한다 | 작성기에서 곱한다 | 표시 이름("원/100엔")과 같은 자리에 둔다. 등락률은 배율과 무관하다 |
| VIX 는 미국 증시, 달러 인덱스는 환율, 비트코인은 원자재 묶음 | 묶음을 더 만든다 | 한두 줄짜리 소제목을 늘리지 않는다 |
| 미 국채 2년은 넣지 않았다 | `2YY=F` | PoC 에서 종가와 전일 종가가 같게 나왔다. 믿을 수 없는 값을 싣지 않는다 |
| 서비스 테스트가 기본 심볼 목록 대신 고정 목록을 쓴다 | `DEFAULT_QUOTE_SYMBOLS` | 기본값을 늘릴 때마다 조립 테스트가 깨지지 않게 한다 |
