# 🛠️ 구현: stock-screening Task 2 — 관심 종목 시세

개별 종목 스크리닝 중 가장 작은 조각이다. DB 이력과 무관하게 기존 시세 경로에 종목 20개를 얹었다.

## 한 일
- `Market` 에 `KR_STOCK`, `US_STOCK` 추가.
- `Settings.watchlist` (기본 20개)와 `Settings.all_symbols()`. `.env.example` 에 `APP_WATCHLIST` 예시.
- 발송 작업이 지수 + 관심 종목을 한 목록으로 수집한다.
- yfinance 예비가 표에 없는 미국 티커(`NVDA`, `BRK-B`)를 그대로 조회한다.
- 작성기에 "국내 관심 종목", "미국 관심 종목" 묶음. 국내 종목 가격은 소수 없이 표기.
- 테스트 12개 추가 (설정 3, 조립 3, 예비 출처 2, 작성기 4).

## 왜 이렇게 했나
| 결정 | 대안 | 고른 이유 |
|---|---|---|
| 관심 종목에 **새 `Market` 값** | `Market.KR`·`US` 에 넣는다 | 휴장 판정이 `KR`·`US` 인 시세의 기준일을 본다. 거래정지된 종목 하나가 "국내 시장 휴장" 안내를 만들면 안 된다. 묶음 제목도 따로 필요하다 |
| `watchlist` 를 `quote_symbols` 와 **별도 설정**으로 | 기본 심볼 목록에 20개를 더한다 | 지수를 그대로 두고 관심 종목만 바꾸거나 비우는 일이 흔하다. `APP_WATCHLIST=[]` 한 줄로 끈다 |
| 합치는 일은 `Settings.all_symbols()` | 발송 작업에서 튜플을 잇는다 | 미리 뽑기 스크립트와 발송 작업이 같은 목록을 쓴다. 테스트할 자리가 생긴다 |
| 기본값은 **고정 목록** | 실행할 때마다 시가총액 순위로 계산 | 분석의 결정. 순위 조회가 실패한 날 관심 종목이 통째로 바뀌거나 사라지지 않는다 |
| yfinance 예비는 **정규식에 맞는 티커만** 통과 | 모든 심볼을 통과 | 국내 6자리 코드는 `.KS`·`.KQ` 가 붙어야 하는데 어느 쪽인지 이 어댑터는 모른다. 틀린 티커로 Yahoo 를 부르지 않는다 |
| 국내 종목은 소수 0자리 | "정수이고 1,000 이상이면" 같은 값 기준 | 원 단위 가격은 항상 정수다. 값이 아니라 시장으로 정하면 지수 표기에 영향이 없다 |
| 관심 종목 묶음은 금리·환율·원자재 **뒤** | 증시 묶음 바로 뒤 | 브리핑의 앞부분은 시장 전체다. 개별 종목은 그다음이다 |
