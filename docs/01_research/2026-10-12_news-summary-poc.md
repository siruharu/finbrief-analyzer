# 🔍 PoC: 실제 하루치 뉴스로 모델·effort 비교 (news-summary Task 1)

> **핵심 질문** — 제목+리드만으로 "입력에 없는 사실 없음·단순 축약 아님"인 한 줄 요약이 되는가. 모델별 차이가 비용 차이를 정당화하는가. 모델·effort·N·줄 길이를 정한다.

## 입력
- 2026-10-12 15:5x KST, `kr_open` 슬롯 기준(lookback 11h)으로 실제 수집한 뉴스 **56건**(한경 15·연합 15·매경 15·Marketaux 9·DART 2). 리드 있는 항목 39건, 리드 길이 중앙값 102자.
- 전처리: 연합 머리말 제거(정규식 `^\([^)]*연합뉴스\)\s*[^=]*=\s*`), `[n] (출처) 제목 — 리드` 한 줄씩, URL 제외.
- 프롬프트(아래 "확정 프롬프트 초안"), 출력 스키마 `Picks{picks: [{index: int, line: str}]}`, `client.messages.parse(..., output_format=Picks)`, `max_tokens=4000`, `output_config={"effort": …}`. thinking 은 기본(어댑티브, 5.5 세대는 끌 수 없음).
- SDK `anthropic==1.13.0`(`uv run --with`, 프로젝트 의존성 미변경). 스크립트는 스크래치, 미커밋.

## 토큰 실측 (`count_tokens`, claude-opus-5-5)
- 시스템 프롬프트 + 56건 입력 = **6,296 토큰**. 호출 시 `input_tokens` 6,665(스키마 포함). 80건으로 환산하면 약 9K — 분석의 추정(10K~15K) 아래.
- 한국어 2,000자 → 2,153 토큰 = **1.08 토큰/글자**. 서드파티 측정(1.06)과 거의 같다. "신형 토크나이저 +30%"는 한국어엔 보이지 않았다.

## 확정값
| 항목 | 확정 | 근거 |
|---|---|---|
| 모델 | **`claude-opus-5-5`** | 사용자 결정(기준선). Haiku 는 선택이 국내에 쏠리고 영향 작은 기사가 섞였다. Sonnet 은 중복 3건. 월 $1~2 차이는 하루 2회 작업에서 결정 요인이 아니다 |
| effort | **`low`** | medium 과 눈에 띄는 품질 차이가 없고(medium 의 [11] 은 오히려 헤드라인 꼴), 비용 30%·시간 60% 절감. thinking 이 출력 토큰의 2/3 를 차지하는 것이 medium 이다 |
| N (`summary_picks`) | **7** | 7건이 한 화면에 들고, 국내 4~5 + 미국 2 꼴로 균형이 나왔다. 수집 56~80건에서 7건은 1/8~1/11 |
| 줄 길이 상한 | **60자** | 4회 28줄 모두 55자 이하. 넘는 줄은 **버린다**(자르면 문장이 깨진다). 프롬프트에 "60자 이내" 유지 |
| `max_tokens` | **2,000** | 최대 관측 1,197(thinking 포함). 4,000 은 과함 |
| 타임아웃 | 120초, 재시도 2회 | 관측 최대 13.9초 |
| 프롬프트 | 아래 초안 그대로. 한 가지 추가: **"국내와 미국을 함께 다룬다"** 를 넣어 Haiku 류의 쏠림을 막는다 | 선택 기준에 시장 균형이 없었다 |

## 확정 프롬프트 초안 (Task 4 의 `SYSTEM_PROMPT`)
```
당신은 한국의 개인 투자자를 위한 아침 금융 브리핑의 뉴스 편집자다.
입력은 지난 밤 수집된 기사 목록이다. 각 항목은 [번호] (출처) 제목 — 리드 형식이고, 리드는 없을 수 있다.

할 일:
1. 브리핑 독자에게 영향이 큰 기사를 최대 {N}건 고른다. 기준: 시장 전체(지수·금리·환율·원자재), 정책·규제, 대형 기업 실적과 공시, 거시 지표. 국내와 미국을 함께 다룬다. 연예·사건사고·광고성 기사는 제외한다.
2. 같은 사건을 다룬 기사가 여러 개면 하나만 고른다.
3. 고른 기사마다 한국어 한 문장(60자 이내)으로 핵심을 쓴다. 영문 기사도 한국어로 쓴다.

규칙:
- 입력에 없는 사실·수치·해석을 쓰지 않는다. 리드가 없는 항목은 제목이 말하는 것만 쓴다.
- 원문 문장을 그대로 옮기거나 단순히 줄이지 말고, 새 문장으로 쓴다.
- 번호(index)는 입력의 번호를 그대로 쓴다. 제목이나 URL 을 다시 쓰지 않는다.
- 고를 만한 기사가 없으면 빈 목록을 돌려준다.
```
